## 📌 Objetivo

Construir sin programar una herramienta de difusión ambiental que obtenga noticias recientes mediante RSS, las resuma con inteligencia artificial y las muestre en una página web, verificando que los resúmenes sean fieles a sus fuentes.

## 🧭 Introducción

Cada día se publican cientos de noticias ambientales, pero pocas personas tienen tiempo de leerlas. La automatización permite filtrar, resumir y difundir esa información para que llegue a más gente de forma clara. En esta práctica construí una página web donde se elige un tema ambiental; Make busca las noticias más recientes en Google News, una inteligencia artificial las resume y la página muestra el resultado con los enlaces a las fuentes.

## 🛠️ Herramientas

- IA generativa (para generar la página web)
- **Make**: Webhooks → RSS → Text aggregator → Make AI Agent → Webhook Response
- **GitHub Pages** (publicación de la página)
